An AI assistant connected through `aquakin mcp` can now change a project as
well as read it: write a flowsheet file, create and edit studies, run them in
the background (with progress and cancel) and read their results, copy, freeze
and unfreeze them. It keeps the editor's safeguards: a flowsheet file, a
study's results or a frozen study's results are replaced only when the
assistant asks for it explicitly. `aquakin.study.list_studies` lists a
project's studies with where each stands.
