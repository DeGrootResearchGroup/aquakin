`aquakin mcp` serves aquakin's tools to an AI assistant (Claude Desktop,
Claude Code, or any app that speaks the Model Context Protocol), running on
your computer under the assistant's own account. The assistant can list and
describe the shipped models and unit kinds, read model files, build a unit
from its settings, check a flowsheet, and search and read the user guide and
the API reference for the installed version. The tools only read. Install with
`pip install "aquakin[mcp]"`; see "Using aquakin from an AI assistant" in the
documentation.
