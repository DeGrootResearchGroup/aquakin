The shipped `asm2d_tud` model's glycogen-formation rates are now finite when
stored glycogen (`XGLY`) is exactly 0, instead of NaN, so a simulation can start
with no glycogen. Results are unchanged wherever `XGLY` is positive. The poly-P
storage rate is still infinite at `XPP = 0`, as in the published model: start a
simulation with `XPP` above 0.
