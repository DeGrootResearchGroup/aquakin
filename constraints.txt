# Reproducible CI lock for aquakin.
#
# Exact, known-good versions of the runtime + test dependency closure -- the set
# the test suite is verified against. The abstract floors in pyproject.toml stay
# loose (no upper caps) so downstream installs of aquakin are not constrained;
# reproducibility for *our* CI lives here. CI installs with:
#
#     pip install -e ".[test]" -c constraints.txt
#
# To refresh after a deliberate dependency upgrade: update the relevant pins to
# the new known-good versions and re-run the suite before committing. Keep this
# in sync with the (raised) floors in pyproject.toml.
